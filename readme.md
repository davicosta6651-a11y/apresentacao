# Página de Apresentação

## Descrição

Este projeto consiste em uma página pessoal desenvolvida como atividade acadêmica, com o objetivo de apresentar informações sobre mim, meus interesses, objetivos, habilidades e tecnologias que conheço ou desejo aprender.

## Objetivo

O objetivo da página é praticar os conceitos básicos e aprender a utilizar o Git e o GitHub para controlar e versionar o projeto.

## Tecnologias utilizadas

* HTML
* CSS
* Git
* GitHub

## Estrutura do projeto

* `index.html` — página principal do projeto.
* `style.css` — arquivo responsável pela estilização da página.
* `README.md` — documentação do projeto.
